# Korean Magnet Tutor — 몰랑이 코어 연동

인도네시아어 화자 1명을 위한 한국어 쓰기 튜터 (Streamlit).

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
`.streamlit/secrets.toml.example` → `.streamlit/secrets.toml` 로 복사 후 `OPENAI_API_KEY`, `APP_PASSWORD`, `TEACHER_PASSWORD` 설정.
Streamlit Cloud에서는 Secrets 패널에 넣는다. API 키 없이도 데모 모드로 돈다(등록된 정답 표현과만 비교).

## 인도네시아어 확인하는 법
- 코드: `L('인도네시아어', '한국어')` 의 두 번째 인자가 한국어 뜻. L()을 안 쓰는 줄에는 `# 🇰🇷` 주석.
- 화면: 사이드바 **교사 모드** → "화면에 한국어 번역 함께 보기" 를 켜면 모든 문구 옆에 〔한국어〕가 뜬다.
- AI 피드백도 `explanation_ko`/`hint_ko`로 한국어 번역을 같이 받아서, 교사 모드에서 AI가 틀린 설명을 했는지 볼 수 있다.
  진도 탭의 '피드백(한국어)' 열에도 저장된다.
- 문제 데이터(`graph_data.py`)는 줄마다 한국어 주석, 각 문제에 `meaning_ko`.

## 이번 버전에서 바뀐 것
**버그 수정**
- NM 시작 확률 치우침: 원본 `add_branch`가 추가할 때마다 정규화해서 `retry` 50% / `hint` 12.5%로 시작했다 → 균등으로 수정. 예전 DB에 피드백이 쌓였다면 교사 탭에서 초기화.
- Markov 자석 낱말이 항상 비어 있던 문제: '먹다'(사전형)로 찾는데 말뭉치엔 '먹어요'만 있었다 → 어간 일치로 찾고, 잡힌 형태를 같이 표시.
- 블록 탭에서 정답 블록이 정답 순서대로 앞에 나와 있었다 → 문제별 고정 셔플.
- 비밀번호에 한글을 넣으면 `hmac.compare_digest` TypeError로 앱이 죽었다 → bytes 비교.
- `engine.save_attempt`가 정답 여부로 전략 가중치를 올리고 있었다(README 원칙과 모순) → 제거. 전략 학습은 학습자 피드백 한 곳에서만.
- 채점 오류가 통째로 숨겨졌다 → 교사 모드에서는 실제 예외 표시.

**실사용 개선**
- 문제 5개 → 20개 (자기소개, 있다/없다, 길·가격 묻기, 부탁, 부정, 미래, 시각, -고 연결 등). 문제마다 인정 답안 목록.
- 고른 전략을 실제로 실행: hint면 힌트만 주고 정답은 접어 둠, blocks면 그 자리에서 블록 연습, example이면 추가 예문, retry면 정답 숨김. 맞히면 전략 없이 '다음 문제'.
- '다음 문제' 버튼: 안 푼 문제 → 복습일 지난 주제 → 숙달도 낮은 주제 순 (예전엔 복습일을 계산만 하고 쓰지 않았다).
- 🔊 발음 듣기 (브라우저 내장 음성, 비용 없음).
- AI가 학습자 문장을 최소 수정한 `corrected` 버전 제공.
- 교사 모드 분리: 학습자 화면에는 학습 기능만. AI 낱말 승인·말뭉치·동적 지도·NM 감사는 교사 탭으로.
  (예전엔 학습자가 AI 낱말을 직접 승인할 수 있어서 사람 검토 단계가 무의미했다.)
- 말뭉치에 연습 문제 정답·예문을 한 번에 넣는 버튼, 중복 승인 방지.

## 단어 은행 (📚 오늘의 단어) — `vocab_bank.py`
**생성 → 검증 → 연습**이 자동으로 돈다.
1. **생성**: 수준(초급1/초급2/중급 ≈ TOPIK 1·2·3급)과 주제(12개)에 맞는 단어 + 예문을 LLM이 만든다.
   수준별로 쓸 수 있는 문법과 예문 최대 어절 수를 프롬프트에 넣고, 이미 있는 단어는 피하게 한다.
   학습자 화면에서 새 단어가 5개 미만이면 8개씩 자동 생성 (교사 탭의 '하루 생성 한도' 안에서).
2. **검증 (인도네시아어를 몰라도 확인 가능하게)**
   - 역번역: 별도 호출이 **인도네시아어만** 보고 한국어로 되돌린다(원문 비공개). `OPENAI_VERIFY_MODEL`로 다른 모델 지정 가능.
   - 코드 규칙: 예문에 그 단어가 있나(불규칙 활용 포함), 수준별 어절 수, 한글 예문, 칸 채움, 역번역 일치.
   - 전부 통과 → `auto`(연습에 사용) / 하나라도 실패 → `flagged`(연습에서 제외, 교사 검토).
   - 교사 탭에서 "원래 한국어 ↔ 역번역 한국어"를 나란히 보고 승인/거절. 승인한 예문만 몰랑이 말뭉치로 들어간다.
   - **엄격 모드**를 켜면 교사 승인 단어(+기본 단어)만 연습에 나온다.
3. **연습 (간격 반복)**: 단어마다 상자 번호. 맞히면 올라가고(1·2·4·8·16·30일 뒤 복습) 틀리면 1로, 5분 뒤 다시.
   상자에 따라 문제가 어려워진다: 단어 카드 → 뜻 고르기 → 한국어 단어 고르기 → 블록으로 예문 조립 → 예문 직접 쓰기.
   연습 문제는 저장된 단어로 코드가 만들기 때문에 **연습 자체는 API 비용이 없다** (직접 쓰기 채점만 AI 사용).
   하루 새 단어 10개. 익힌 단어가 80% 넘으면 다음 수준 안내.
4. 기본 단어 36개(`seed`)는 Claude가 쓴 것이고 원어민 검수 전이다. API 키 없이도 바로 연습 가능.

## 그대로인 한계
- 역번역·규칙 검사는 '이상 신호' 감지일 뿐 정답 보증이 아니다. 같은 회사 모델끼리는 같은 실수를 할 수 있다.
- 몰랑이 원본 `data/molang.pkl`은 포함·로드하지 않는다.
- NM 전략 학습은 학습자의 '도움 됨/안 됨' 주관 피드백이다. 실제 학습 효과 검증이 아니다.
- Markov·공기 관계는 문법 관계의 증거가 아니다. 어간 매칭도 형태소 분석이 아니다.
- 데모 채점은 등록된 표현과만 비교한다. 진단(시제/조사)도 단순 규칙.
- Streamlit Community Cloud의 SQLite는 재시작 시 사라질 수 있다 → 장기 사용이면 Supabase 등으로.
- 공용 비밀번호는 개인별 인증이 아니다.
- 인도네시아어 문구는 원어민 검수를 거치지 않았다. 학습자에게 어색한 표현을 알려 달라고 하면 가장 빠르다.
